# PlayPointer для Windows

Предварительная версия для **Windows 11 x64**. Распакуйте portable ZIP в одну папку и откройте `PlayPointer.exe`. Папка `assets` должна находиться рядом с приложением. В автономной сборке среда .NET уже включена. Права администратора не нужны.

Для обновления выберите **«Завершить PlayPointer»** в меню значка рядом с часами. Распакуйте новый ZIP в отдельную папку и запустите `PlayPointer.exe` из неё.

- **Управление**: указатель отмечает точку системного курсора. Щелчки, перетаскивание и прокрутка идут в открытые приложения как обычно.
- **Рисование**: нажмите основную кнопку мыши и ведите указатель. Рисование работает в рабочей области экранов. Чтобы временно управлять окнами, удерживайте **Alt**. Рисунок остаётся виден в режиме управления и стирается при выключении указателя.
- **Каталог**: выберите указатель по категории или названию. Здесь есть руки, пиксельные стрелки, котики, палочка, Nyan Cat, Фрай и музыкальный котик. Последний чередует лапы и звуки на основных кликах. Звук и анимацию можно отключить на панели.
- **Горячие клавиши**: **Ctrl+Alt+H** — включить или выключить; **Ctrl+Alt+D** — сменить режим; **Ctrl+Alt+X** — стереть рисунок; **Ctrl+Alt+Esc** — выключить указатель. Если сочетание занято, используйте панель или меню значка рядом с часами. Там же есть команда **«Завершить PlayPointer»**.

Windows-версия не устанавливает глобальные перехватчики мыши и не меняет системный курсор. В режиме управления анимация и звук запускаются по событиям нажатия кнопки мыши. Лазерная точка обведена кольцом, чтобы место клика было заметно и над ссылками в браузере. Переключение экранов или изменение рабочей области сбрасывает рисунок. Поведение поверх полноэкранных игр и окон Windows на защищённом рабочем столе не гарантируется.

Приложение не запускается автоматически, не записывает координаты и нажатия и не делает сетевых запросов. Рисунок хранится в памяти до очистки или завершения приложения. В `%LOCALAPPDATA%\PlayPointer\preferences.json` хранятся только выбранный образ, звук и анимация. Ссылка обратной связи открывает браузер по нажатию.

## Сборка

Требуется .NET SDK 10. Из корня репозитория:

```powershell
dotnet build windows/PlayPointer.Windows.csproj -c Release
dotnet publish windows/PlayPointer.Windows.csproj -c Release -r win-x64 --self-contained true -o dist/playpointer-windows-x64
```

Проект разрешает кросс-сборку с macOS и Linux. Для проверки интерфейса, ввода и разных масштабов мониторов нужен запуск на Windows. Папку публикации можно упаковать целиком: PNG и WAV копируются из общих ресурсов репозитория.
