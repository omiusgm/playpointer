# PlayPointer

PlayPointer — забавные указатели для демонстраций экрана с режимами управления компьютером и рисования. PlayPointer развивает Владимир Кривошеев. Приложение выросло из [TinyHand](https://github.com/nilbuild/tinyhand) Камрана Ахмеда. Авторство и лицензия MIT исходного проекта сохранены в [LICENSE](LICENSE).

## Как пользоваться

- Нажмите значок в строке меню или **⌃⌥H**, чтобы включить указатель. Если сочетание занято, измените его в настройках.
- В режиме **«Управление»** можно щёлкать, перетаскивать и прокручивать страницы, не выключая указатель.
- Режим **«Рисование»** позволяет рисовать поверх окон. Как выдать разрешение, описано в пункте **«Как включить рисование…»** в меню PlayPointer. Удерживайте Option, чтобы временно управлять приложениями.
- **Esc** закрывает каталог. Если каталог закрыт, **Esc** выключает указатель и стирает рисунок. **⌃⌥X** только стирает рисунок.
- Прокручивайте указатели на нижней панели двумя пальцами. Недавние идут первыми. **«+»** открывает каталог. Лапка догоняет лазерную точку, которая отмечает место клика. При нажатии появляется подсветка, а некоторые указатели меняют позу. Волшебная палочка выпускает искры со своим звуком. У летящего Nyan Cat радужный след тянется от хвоста.
- Музыкальный котик стучит по очереди двумя лапками и оставляет нотки при движении. Кнопка звука на панели отключает его удары.

## Предварительная версия для Windows

Возьмите ZIP для Windows 11 x64 на странице [Releases](https://github.com/omiusgm/playpointer/releases). Распакуйте весь архив в одну папку и запустите `PlayPointer.exe`. В архив уже включена среда .NET. Сборку проверили на этапе компиляции и упаковки. Запуск и работу в Windows ещё предстоит проверить.

Чтобы собрать из исходников, используйте .NET 10 SDK:

```sh
dotnet publish windows/PlayPointer.Windows.csproj -c Release -r win-x64 --self-contained true
```

## Сборка для macOS

Нужны macOS 13 или новее, Xcode и Swift. Выполните:

```sh
./scripts/build-app.sh
```

Результат — `dist/PlayPointer.app`. Локальная сборка подписывается ad hoc: это не подпись идентифицированного разработчика и не нотарификация Apple. На другом Mac macOS может не разрешить запуск. Подписанного и нотарифицированного релиза пока нет. Автоматические обновления в форке отключены.

## Доступ и конфиденциальность

Разрешение для рисования даёт приложению широкие возможности управления Mac. Его можно отозвать в разделе **«Конфиденциальность и безопасность»**. На macOS 27 выберите **«Управление устройством и доступ к данным»**, на предыдущих версиях macOS — **«Универсальный доступ»**. В обоих случаях найдите строку PlayPointer. Если после обновления переключатель включён, а приложение запрашивает доступ, удалите эту запись кнопкой **«−»** и снова добавьте PlayPointer из папки **«Программы»** кнопкой **«+»**. При обычном управлении перехватчик рисования не включается.

Форк не включает автозапуск при первом старте и не записывает журнал координат и нажатий. Автозапуск можно включить самостоятельно. Функция создания собственной руки может открыть ChatGPT в браузере с введённым пользователем текстом запроса. Подробнее о проверке оригинала и её ограничениях — в [RESEARCH.md](RESEARCH.md).

Образы вдохновлены публичными референсами и частично созданы с помощью ImageGen. Персонажи и связанные с ними товарные знаки принадлежат соответствующим правообладателям. Проект не является официальным продуктом их владельцев.
